# Confirmed design decisions — 2026-11-14

- One school system, multiple campuses.
- Main Windows desktop: one assigned campus offline; cross-campus online view requires permission and is not cached.
- Android and other PCs: online-only entry in pilot.
- Automatically sync when internet returns, plus Sync Now. Unresolved conflicts reviewed by authorized users.
- Offline approval requests saved pending, finalized only after online authorization.
- Owner configures backup destinations; recover from cloud plus verified independent backup.
- Principal may see consolidated summaries; Owner separately grants cross-campus details.
- Admin creates admissions; Principal approves if Owner enables approval.
- Conditional admissions allowed with required missing-document deadline; no auto-deletion.
- Fees by campus/class and student-specific transport; partial/advance payments, selected-category discounts.
- Attendance: Present, Absent, Leave, Late; leave not counted attended; attendance staff today only, Admin historical correction.
- Employees fixed salary, manually chosen deductions, advance recovery, partial salary payment and configurable approval.
- Each campus cash/bank, mandatory daily closing and Owner-approved financial corrections.
- Cash/bank receipts only; no payment gateway in pilot.
- App English first; optional Pakistani Urdu if it does not delay release.
- 21-day working pilot target; financial safety outranks secondary modules.
