# 21-day pilot schedule

Each day contains five task IDs DNN-T01..T05 in planning/TASKS.md. Baseline 114 tracked tasks (9 setup + 105 daily).

Week 1 (D01–07): repository, environment, school foundation, auth/RLS, students, local sync skeleton, admissions and fee plan.
Week 2 (D08–14): fee receipts, advances, prints, attendance, employees, payroll, expenses and cashbook.
Week 3 (D15–21): approvals, transfers, conflict resolution, cash closing, backups, reporting and pilot packaging.

**Quality gate:** no live financial use without verified two-campus RLS, idempotent receipts, safe offline/online reconnection and restorative backups. Secondary inventory automation should be deferred if necessary.
