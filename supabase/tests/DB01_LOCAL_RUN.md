## Database migration steps
1. Check out the draft branch `db/db01-db02-schema-drafts`.
2. Generate the migration filename with the real CLI (never invent a timestamp):

       supabase migration new db01_foundation

3. Locate the newly generated SQL file in `supabase/migrations/`.
4. Copy the reviewed SQL from `supabase/drafts/DB01_foundation.sql` into that file. The draft currently includes `BEGIN` and `COMMIT`, so review migration-transaction behavior before applying.
5. Run `supabase db reset` **only against your disposable LOCAL database**.
6. Confirm it applies cleanly and that 12 public DB01 tables have RLS enabled.
